# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/webstat` | Root-Webstat status and reload | `rootwebstat.admin` | `/<command> [reload/status/push]` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootwebstat.admin` | Manage Root-Webstat | `op` |
